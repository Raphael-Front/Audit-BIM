Botões & Pills

Componente pill: altura 25px, padding 0 8px, border-radius rounded (9999px). Usado para filtros, labels e ações na toolbar.

/* Pill Component */ ._root { font-size: var(--font-size-small); /* 13px */ font-weight: var(--font-weight-medium); /* 500 */ background: var(--color-bg-primary); border-radius: var(--radius-rounded); /* 9999px */ border: 1px solid var(--color-border-secondary); align-items: center; gap: 6px; height: 25px; padding: 0 8px; display: inline-flex; } /* Dot indicator */ ._root:before { content: ""; width: var(--label-dot-size, 9px); height: var(--label-dot-size, 9px); background: var(--color); border-radius: var(--radius-circle); /* 50% */ flex-shrink: 0; }

Inputs

Code

Tipografia monospace com Berkeley Mono. Inline code com background quaternary e border-radius 0.2em.

Use --font-size-small para texto de UI e --font-weight-medium para labels.

/* Berkeley Mono Variable */ @font-face { font-family: Berkeley Mono; font-style: normal; font-weight: 100 900; font-display: swap; src: url(...) format("woff2"); } /* Inline code */ code:not(pre code) { background-color: var(--color-bg-quaternary); border: 1px solid var(--color-border-primary); border-radius: .2em; padding: .15em .25em; font-size: .875em; }
