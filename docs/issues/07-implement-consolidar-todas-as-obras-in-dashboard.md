# Implement "consolidar todas as obras" in Dashboard

## Overview

Quando o contexto for "Todas as obras" (`selectedObraId = null`), o Dashboard exibe a visão consolidada: as funções de métricas/gráficos rodam sem filtro de obra, agregando todas. Garantir que cartões e gráficos façam sentido no modo agregado (rótulos e totais).
